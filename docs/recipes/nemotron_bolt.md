# Serve Nemotron Bolt on MI100

Run NVIDIA’s Nemotron 3.5 Bolt 74B-A9B-24GB as a chat API with text, image and video input on two, three or four 32 GiB MI100s. Allow about 24 GiB of disk for NVIDIA’s [packed target](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB) and [LiLiCorr draft](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Bolt-74B-A9B-24GB-LiLiCorr).

## Docker Compose

From the root of your [MI100 checkout](mi100-install.md#docker), start the server. Set `MI100_CARDS` to your card count and use `MI100_XGMI=off` for PCIe. The launcher downloads both checkpoints on first use.

```bash
MI100_RECIPE=bolt MI100_CARDS=4 MI100_XGMI=on \
  docker compose -f docker/mi100/compose.yaml up --build --wait
```

## Send a chat

When Compose reports the service healthy, it is ready at `http://127.0.0.1:8020/v1`. Use `nemotron-bolt` as the model ID. This example reads the key generated by the launcher. If you supplied a key, use that value for `api_key`.

```bash
api_key="$(docker compose -f docker/mi100/compose.yaml exec -T serve cat /cache/mi100/api.key)"
curl -fsS http://127.0.0.1:8020/v1/chat/completions \
  -H "Authorization: Bearer $api_key" \
  -H 'Content-Type: application/json' \
  -d '{"model":"nemotron-bolt","messages":[{"role":"user","content":"Suggest a one-pot dinner."}],"max_tokens":256}'
```

Stop the container with `docker compose -f docker/mi100/compose.yaml down`. The named volume keeps the downloads for the next start.

## Native serving

After [building the native MI100 environment](mi100-install.md#native), run these commands from the checkout.

```bash
export MI100_RECIPE=bolt MI100_CARDS=4 MI100_XGMI=on
scripts/mi100-serve.sh start
```

Use the [native API key](mi100-install.md#api-access) for the chat request above. From the same shell, run `scripts/mi100-serve.sh status` to see the service state or `scripts/mi100-serve.sh stop` to shut it down.

## Memory and context

On four cards the launcher allows eight concurrent requests and up to 262,144 input and output tokens combined per request. On two or three cards it sizes the context to available GPU memory. Allow 24 GiB of system RAM for the default CPU prefix cache, plus memory for loading and running the server. Set `KV_OFFLOAD_BYTES` to change the CPU cache budget.
