# Serve Flint on MI100

Run Flint as a chat and tool-calling API on two, three or four 32 GiB MI100s. Allow about 39 GiB of disk for the [INT8 target](https://huggingface.co/voodooquant/Flint-GPTQ-INT8-PTQR) and its [DFlash2 draft](https://huggingface.co/voodooquant/Flint-DFlash2-GPTQ-INT8-PTQR).

## Docker Compose

From the root of your [MI100 checkout](mi100-install.md#docker), start the server. Set `MI100_CARDS` to your card count and use `MI100_XGMI=off` for PCIe. The launcher downloads both checkpoints on first use.

```bash
MI100_RECIPE=flint MI100_CARDS=4 MI100_XGMI=on \
  docker compose -f docker/mi100/compose.yaml up --build --wait
```

## Send a chat

When Compose reports the service healthy, it is ready at `http://127.0.0.1:8020/v1`. Use `flint` as the model ID. This example reads the key generated by the launcher. If you supplied a key, use that value for `api_key`.

```bash
api_key="$(docker compose -f docker/mi100/compose.yaml exec -T serve cat /cache/mi100/api.key)"
curl -fsS http://127.0.0.1:8020/v1/chat/completions \
  -H "Authorization: Bearer $api_key" \
  -H 'Content-Type: application/json' \
  -d '{"model":"flint","messages":[{"role":"user","content":"Suggest a one-pot dinner."}],"max_tokens":256}'
```

Stop the container with `docker compose -f docker/mi100/compose.yaml down`. The named volume keeps the downloads for the next start.

## Native serving

After [building the native MI100 environment](mi100-install.md#native), run these commands from the checkout.

```bash
export MI100_RECIPE=flint MI100_CARDS=4 MI100_XGMI=on
scripts/mi100-serve.sh start
```

Use the [native API key](mi100-install.md#api-access) for the chat request above. From the same shell, run `scripts/mi100-serve.sh status` to see the service state or `scripts/mi100-serve.sh stop` to shut it down.

## Memory and context

On four cards the launcher allows 12 concurrent requests and up to 524,288 input and output tokens combined per request. On two or three cards it sizes the context to available GPU memory. Active requests share the GPU KV cache.
